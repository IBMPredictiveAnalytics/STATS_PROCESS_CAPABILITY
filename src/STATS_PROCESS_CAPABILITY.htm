Process Capability Analysis

Use this procedure to assess whether a process is operating within its specified engineering or quality limits. Given one or more continuous measurement variables, it computes the full suite of process capability and performance indices (Cp, Cpk, Pp, Ppk, Cpm), along with supporting statistics including parts per million (PPM) defective, defects per million opportunities (DPMO), sigma level (Z-bench), yield, percentiles, skewness, kurtosis, and confidence intervals.

The procedure requires at least one specification limit (LSL or USL) to compute capability indices. A target value (T) is required for the Cpm index. Select the process variable(s) to analyze on the main tab. Optionally, a grouping variable can be specified to compute within-subgroup (short-term) sigma estimates; without a grouping variable, individual moving ranges are used for within-subgroup estimation.

All analyses are produced variable by variable. Missing values are deleted listwise within each variable. Only variables with a scale (numeric continuous) measurement level should be analyzed. At least 2 non-missing observations are required per variable; fewer than 30 observations will produce a warning, as capability indices are unreliable with very small samples.

Output includes SPSS pivot tables in the Output Viewer plus an interactive HTML dashboard that summarizes key indices, gauge indicators, and distribution plots in a self-contained report file. The HTML report can optionally include a company logo and analyst identification fields.

Variables Tab

Move one or more continuous process measurement variables into the Process Variable(s) list. These are the measurements to be evaluated for conformance to specification limits. All listed variables are analyzed independently; each produces its own set of output tables, charts, and HTML report section.

Optionally, move a categorical grouping variable into the Subgroup (Grouping) Variable field. The grouping variable defines rational subgroups (e.g., machine shift, production batch, time period) used to estimate within-subgroup (short-term) process sigma. Within-subgroup sigma is used to compute potential capability indices (Cp, Cpk) that reflect the process's inherent variation, separate from between-subgroup drift. If no grouping variable is specified, within-subgroup sigma is estimated from individual consecutive moving ranges (MR-bar method).

Specification Limits and Target

Enter the engineering or quality specification limits that define conforming process output. At least one of LSL or USL must be provided to compute capability indices. If only one limit is provided, one-sided capability indices are computed where applicable.

Lower Specification Limit (LSL). The minimum acceptable value for the process characteristic. Values below this limit are nonconforming.

Upper Specification Limit (USL). The maximum acceptable value for the process characteristic. Values above this limit are nonconforming.

Target (T). The nominal or ideal value of the process characteristic, typically the midpoint of the specification range. The target is required to compute the Cpm (Taguchi) index. If not specified, Cpm is not computed.

Sigma Multiplier

The sigma multiplier defines the number of standard deviations used in the tolerance interval for capability calculations. The default and most widely used value is 6, corresponding to ±3σ on each side of the process mean. This is the basis for the "six sigma" quality philosophy, under which a perfectly centred process at Cp = 1.000 produces 2,700 defects per million.

Other common choices include 3 (±1.5σ, used in some one-sided or tighter-tolerance settings) and 4 (±2σ). A Custom value may be entered for non-standard applications. The sigma multiplier divides the specification width when computing Cp and related indices: Cp = (USL − LSL) / (sigma_multiplier × σ).

Note that Cpm is always computed using a fixed divisor of 6σ per ISO 22514, regardless of the sigma multiplier selected here.

Within-Sigma Estimation Method

Short-term (within-subgroup) sigma is estimated from the data using one of four methods. This sigma estimate is used to compute potential capability indices (Cp, Cpk) which reflect the process's inherent (best-case) variation.

Pooled Standard Deviation (POOLED). Computes the pooled within-subgroup standard deviation across all subgroups defined by the grouping variable. This is the most statistically efficient estimator when subgroup sizes are approximately equal and is the AIAG default for variable subgroup sizes. Requires a grouping variable.

R-bar / d2 (RBAR). Estimates within-subgroup sigma from the average subgroup range divided by the control chart unbiasing constant d2. Appropriate for small, fixed subgroup sizes (typically n = 2 to 8). Requires a grouping variable.

S-bar / c4 (SBAR). Estimates within-subgroup sigma from the average subgroup standard deviation divided by the unbiasing constant c4. Generally preferred over R-bar for subgroup sizes greater than 8. Requires a grouping variable.

Moving Range / d2 (MRBAR). Estimates within-subgroup sigma from the average consecutive moving range of individual observations (MR-bar), divided by d2 = 1.128. This is the default method when no grouping variable is specified, and is appropriate for individual measurement data (subgroup size = 1). It captures only short-term, point-to-point variation.

Confidence Level

Specify the confidence level to use for all interval estimates. The default is 0.95 (95%). This level applies to confidence intervals for the process mean, standard deviation, and Cpk index when the corresponding interval options are selected. Enter a value strictly between 0 and 1 (e.g., 0.90 for 90%, 0.99 for 99%).

Statistics Tab

Select the optional statistics to include in the output pivot tables. All statistics are computed per process variable.

Normality Tests. Computes up to four formal tests of the normality assumption for the process data: Anderson-Darling, Shapiro-Wilk, Lilliefors (Kolmogorov-Smirnov), and Jarque-Bera. A normality assessment table is produced showing the test statistic, degrees of freedom, and p-value for each test, along with an overall normality verdict. Because capability indices Cp, Cpk, Pp, and Ppk assume a normal process distribution, significant departures from normality should prompt consideration of the Box-Cox transformation or the Distribution Advisor.

PPM (Parts Per Million). Reports observed and expected nonconforming parts per million. Expected PPM is computed from the fitted normal distribution using both within-subgroup (potential) and overall (actual) sigma, separately for the LSL tail, USL tail, and total. Observed PPM counts actual out-of-specification values in the sample.

Cpm (Taguchi Index). Computes the Cpm capability index, which accounts for process deviation from the target value T in addition to process spread. Requires a target value. If no target is specified this option is ignored.

Z-Bench (Sigma Level). Reports the benchmark Z score for the process. ZLT (long-term Z, or Z-bench overall) is derived from total expected PPM; ZST (short-term Z) adds the industry-standard 1.5-sigma shift: ZST = ZLT + 1.5. Both within-based and overall-based sigma-level values are reported.

DPMO. Reports Defects Per Million Opportunities, numerically identical to total expected PPM when each measurement opportunity produces at most one defect opportunity.

Yield. Reports the expected process yield as a percentage: Yield = (1 − total expected PPM / 1,000,000) × 100. Both within-based and overall-based yields are reported.

Skewness and Kurtosis. Reports the sample skewness and excess kurtosis of the process data, with their standard errors. Skewness near zero and kurtosis near zero are consistent with normality. Large absolute values indicate distributional shape departures that may invalidate standard capability indices.

Percentiles. Reports the 0.135th, 50th (median), and 99.865th percentiles of the data. These percentiles correspond to −3σ and +3σ under normality and allow a distribution-free assessment of the proportion of data within the specification range.

I-MR Control Limits. Computes and reports the control limits (UCL, CL, LCL) for an Individuals (X) and Moving Range (MR) control chart, based on the within-subgroup sigma estimate. Useful for monitoring process stability.

Outliers. Identifies observations that fall more than 3 within-subgroup standard deviations from the process mean. Outlier counts and the flagged observation indices are reported.

CI for Mean. Reports a two-sided confidence interval for the process mean at the selected confidence level.

CI for Std Dev. Reports a chi-squared-based confidence interval for the process standard deviation (both within and overall) at the selected confidence level.

CI for Cpk. Reports a normal-theory approximate confidence interval for the Cpk index at the selected confidence level, using the standard asymptotic variance formula.

Options Tab

Box-Cox Transformation. When selected, the procedure automatically searches for the optimal Box-Cox power transformation parameter (λ) that best normalises the process data, using maximum likelihood estimation over a grid of candidate λ values from −2 to 2. Capability indices are then computed on the transformed scale and back-transformed results are reported where possible. This option is useful when normality tests indicate significant non-normality. The estimated λ and its 95% confidence interval are reported.

Benchmark Comparison. When selected, the capability indices are compared against standard industry benchmark thresholds. A colour-coded report card table is produced showing whether each index meets or exceeds typical minimum acceptable levels (e.g., Cpk ≥ 1.33 for a capable process, Cpk ≥ 1.67 for a highly capable process) and Six Sigma levels.

HTML Report Card. Produces an interactive HTML summary dashboard for each process variable. The dashboard includes a gauge visualization of the overall process score, colour-coded capability index summary table, distribution plot with specification limit overlays, and key performance metrics (PPM, Yield, Sigma Level). The HTML file is saved to the SPSS default output directory. Report metadata (analyst name, reviewer, company) can be set on the Report tab.

Charts Tab

Select the charts to produce. All charts are rendered as high-resolution graphics in the SPSS Output Viewer. Charts are produced per process variable.

Histogram with Normal Curve. A histogram of the process data with a fitted normal density curve overlaid, along with vertical reference lines for the process mean, LSL, USL, and ±3σ boundaries. The histogram provides an immediate visual assessment of process centring, spread, and shape relative to the specification limits.

Normal Probability Plot. A Q-Q plot of the ordered process data against normal quantiles. Points following a straight diagonal line support the normality assumption. Systematic curvature, S-shapes, or outlier points at the extremes indicate departures from normality that may affect the validity of capability indices.

Capability Plot. A combined chart showing the process data distribution (histogram and/or kernel density estimate) with specification limits, process mean, and ±3σ lines. The capability plot is the standard graphical output for process capability studies and gives an at-a-glance view of how well the process fits within its tolerance band.

Run Chart. A time-order sequence plot of the individual measurements against their observation order (or subgroup number if a grouping variable is specified). The process mean is shown as a centre line. Run charts reveal trends, shifts, cycles, and other non-random patterns that indicate process instability and may invalidate capability indices calculated under the assumption of a stable, in-control process.

Box Plot. A box-and-whisker plot of the process data, optionally split by subgroup if a grouping variable is specified. The box plot summarises the five-number summary (minimum, Q1, median, Q3, maximum) and flags potential outliers as individual points beyond the whiskers (1.5 × IQR). Useful for comparing distribution shape and spread across subgroups.

Summary Report Chart. A composite chart panel that consolidates the capability histogram, normal probability plot, run chart, and key index values into a single graphical summary suitable for inclusion in quality reports or presentations. This is the most information-dense single output of the procedure.

I-MR Chart. An Individuals and Moving Range (I-MR) control chart. The Individuals chart plots each observation with UCL and LCL control limits; the Moving Range chart plots the consecutive absolute differences between observations with its own control limits. Points outside control limits or non-random patterns indicate the process is not in statistical control, a prerequisite for valid capability analysis.

Violin Plot. A violin plot combines a box plot with a mirrored kernel density estimate, showing the full distributional shape, median, interquartile range, and data spread simultaneously. Violin plots are particularly effective for comparing the shape of process distributions across subgroups.

Kernel Density Estimate (KDE). A smooth non-parametric density estimate of the process data using a Gaussian kernel with bandwidth selected by Silverman's rule. Overlaid with the specification limits, the KDE provides a flexible representation of the process distribution that does not impose the normality assumption of the histogram normal curve.

Six-Pack Chart. The process capability six-pack displays six standard diagnostic charts in a single panel: run chart, I chart, MR chart, histogram with capability, normal Q-Q plot, and a capability indices summary. The six-pack is the standard comprehensive graphical summary used in AIAG capability studies and provides everything needed to assess process stability and capability in one view.

Distribution Advisor Tab

The Distribution Advisor fits up to 16 candidate probability distributions to the process data and identifies the best-fitting family. This is valuable when normality tests indicate significant departures from normality or when the process is known to produce skewed or bounded data (e.g., cycle times, concentrations, surface roughness).

Enable Distribution Advisor. When checked, the procedure fits all candidate distributions and produces a ranked comparison table showing goodness-of-fit statistics (AIC, BIC, and a composite score) for each distribution.

Significance Level. The alpha level used for the goodness-of-fit tests within the Distribution Advisor. Default is 0.05. This controls the threshold for flagging distributions as a poor fit.

Include 3-Parameter Distributions. When checked, three-parameter variants of the Weibull, lognormal, and gamma distributions (which include a location/threshold parameter) are added to the candidate set. Three-parameter distributions can fit data that does not start at zero but are more prone to overfitting with small samples.

Apply Best-Fit Transform (PIT Transform). When checked and a best-fit distribution is identified, the Probability Integral Transform (PIT) is applied to map the process data to a uniform distribution, then to a standard normal distribution, and distribution-adjusted capability indices are computed on the transformed scale. The PIT transform is a theoretically exact normalisation when the correct distribution family is used, and provides capability indices that are valid regardless of the original data distribution.

Report Tab

These fields populate the header of the HTML dashboard report produced when the HTML Report Card option is enabled.

Prepared By. Name of the analyst or engineer who conducted the capability study.

Reviewed By. Name of the quality manager or reviewer.

Company / Organisation. Organisation name to appear in the report header.

Logo Path. Full file path to a PNG or JPG logo image to embed in the report header. Leave blank to omit the logo.

Export Logs. When checked, internal diagnostic log messages are appended to the HTML report. Intended for troubleshooting.

Data Generation Tab

This tab allows the procedure to generate a simulated normal dataset for demonstration or teaching purposes instead of analysing existing data. When enabled, the procedure ignores any variables specified on the Variables tab and instead generates a random normal sample with the specified parameters.

Generate Simulated Data. Check to activate data generation mode.

Sample Size. Number of observations to generate. Default is 100.

Mean. Population mean of the simulated normal distribution. Default is 10.0.

Standard Deviation. Population standard deviation of the simulated normal distribution. Default is 1.0.

Information on the Capability Indices

Process capability indices quantify the relationship between the natural variability of a process and its engineering specification limits. They are computed under the assumption that the process is in statistical control (stable over time) and that the process output follows a normal distribution. Indices based on within-subgroup sigma (σW) measure potential (short-term) capability, while indices based on overall sigma (σT) measure actual (long-term) performance. Higher values indicate better capability; a value of 1.00 means the process spread exactly fills the specification tolerance.

Cp — Process Capability Index

Cp (also written Cp) measures the potential capability of the process by comparing the specification width to the process spread, using within-subgroup sigma. It does not account for process centring.

Cp = (USL − LSL) / (sigma_multiplier × σW)

A Cp of 1.00 means the process spread equals the specification tolerance (±3σ boundaries just touch the spec limits). Cp ≥ 1.33 is a common minimum standard for a capable process; Cp ≥ 1.67 indicates a highly capable process. Cp requires both LSL and USL; it is not defined for one-sided specifications.

Example: A turning operation produces shaft diameters with LSL = 49.5 mm and USL = 50.5 mm (tolerance = 1.0 mm). The within-subgroup standard deviation is σW = 0.12 mm. Cp = 1.0 / (6 × 0.12) = 1.39, indicating a capable process whose natural spread fits comfortably within the tolerance.

Cpk — Process Capability Index (Centring-Adjusted)

Cpk adjusts Cp for the actual process centring by taking the minimum of the upper and lower one-sided indices:

Cpu = (USL − μ) / (sigma_multiplier/2 × σW)   Cpl = (μ − LSL) / (sigma_multiplier/2 × σW)

Cpk = min(Cpu, Cpl)

Cpk ≤ Cp always; equality holds only when the process is perfectly centred at the midpoint of the specification range. Cpk can be negative if the process mean is outside a specification limit. The same benchmark thresholds apply: Cpk ≥ 1.33 for capability, ≥ 1.67 for high capability.

Example: Using the shaft example above with σW = 0.12 mm and process mean μ = 50.15 mm: Cpu = (50.5 − 50.15) / 0.36 = 0.97, Cpl = (50.15 − 49.5) / 0.36 = 1.81, Cpk = min(0.97, 1.81) = 0.97. The process is not capable despite adequate spread (Cp = 1.39) because the mean is shifted toward the upper limit.

Pp — Process Performance Index

Pp is the performance analogue of Cp, computed using overall (total) standard deviation σT instead of within-subgroup sigma. It reflects actual long-term process performance including between-subgroup variation (e.g., tool wear, raw material variation, operator differences).

Pp = (USL − LSL) / (sigma_multiplier × σT)

Because σT ≥ σW, Pp ≤ Cp. A large gap between Cp and Pp indicates significant between-subgroup variation that should be investigated. Pp requires both LSL and USL.

Example: In the shaft example, if the overall standard deviation across all subgroups is σT = 0.18 mm (higher than σW = 0.12 due to between-batch variation), then Pp = 1.0 / (6 × 0.18) = 0.93. The process does not meet performance requirements even though its potential capability is adequate.

Ppk — Process Performance Index (Centring-Adjusted)

Ppk is the performance analogue of Cpk, using overall sigma for both spread and centering assessment:

Ppu = (USL − μ) / (sigma_multiplier/2 × σT)   Ppl = (μ − LSL) / (sigma_multiplier/2 × σT)

Ppk = min(Ppu, Ppl)

Ppk represents the actual long-term centring-adjusted capability. It is the most conservative of the four basic indices and most directly predicts the fraction of nonconforming output observed in practice.

Example: With μ = 50.15 mm and σT = 0.18 mm: Ppu = (50.5 − 50.15) / 0.54 = 0.65, Ppl = (50.15 − 49.5) / 0.54 = 1.20, Ppk = 0.65. The actual long-term performance is poor; corrective action on both centring and between-batch variation is needed.

Cpm — Taguchi Capability Index

Cpm (also called the Taguchi index) penalises deviation of the process mean from the target value T, not just from the nearest specification limit. It is defined as:

Cpm = (USL − LSL) / (6 × τ)   where  τ2 = σT2 + (μ − T)2

The denominator 6 is fixed per ISO 22514 regardless of the sigma multiplier setting. When μ = T, Cpm = Pp. As the mean moves away from the target, Cpm decreases faster than Pp, directly reflecting the economic loss from off-target production. Cpm requires a target value T and both specification limits.

Example: With LSL = 49.5, USL = 50.5, T = 50.0 (midpoint), μ = 50.15, σT = 0.18 mm: τ2 = 0.182 + (50.15 − 50.0)2 = 0.0324 + 0.0225 = 0.0549, τ = 0.234. Cpm = 1.0 / (6 × 0.234) = 0.71. The off-target mean significantly degrades the Taguchi index relative to Pp = 0.93.

Information on the Normality Tests

Standard capability indices (Cp, Cpk, Pp, Ppk) are derived under the assumption that the process follows a normal distribution. Formal normality tests assess the null hypothesis that the data are drawn from a normal population. A significant result (small p-value, typically p < 0.05) suggests departures from normality that may affect the validity of the indices. However, with large samples even trivial departures from normality become statistically significant, while with small samples the tests have low power. Graphical assessment (probability plots, histograms) should complement formal tests.

Anderson-Darling Test

The Anderson-Darling (AD) test is based on the weighted squared differences between the empirical cumulative distribution function (ECDF) of the sample and the cumulative distribution function of the fitted normal distribution. The weighting gives more emphasis to the tails than the Kolmogorov-Smirnov test, making the AD test more sensitive to tail departures from normality. The test statistic A2 is compared to critical values or converted to a p-value. Small p-values indicate non-normality.

Example: In process capability analysis, the AD test is routinely applied to verify the normality assumption before reporting Cpk. If the process generates many near-zero measurements with an occasional large value (e.g., contamination events), the AD test will typically detect this right-skew and flag it with a significant result, prompting the analyst to consider a lognormal or Weibull capability model.

Shapiro-Wilk Test

The Shapiro-Wilk test evaluates normality by computing the ratio of the best linear unbiased estimator of the standard deviation (based on order statistic weights) to the usual sample standard deviation. Values of the test statistic W close to 1 support normality; values significantly below 1 indicate non-normality. The Shapiro-Wilk test is generally regarded as one of the most powerful omnibus tests for normality and is recommended for sample sizes up to 5000.

Example: A quality engineer analysing fill weights from a bottling line applies the Shapiro-Wilk test to each production shift's sample (n = 25). A result of W = 0.91, p = 0.032 for the night shift but W = 0.97, p = 0.61 for the day shift suggests the night shift process may have a different distributional shape, warranting investigation of the filling equipment setup.

Lilliefors (Kolmogorov-Smirnov) Test

The Kolmogorov-Smirnov (K-S) test measures the maximum absolute difference between the ECDF of the sample and the CDF of the reference normal distribution. The Lilliefors correction applies when the normal distribution parameters are estimated from the data (as is always the case in capability analysis) rather than known in advance. Without the Lilliefors correction the K-S test is conservative (too lenient) when parameters are estimated. The Lilliefors test uses simulation-based critical values to account for parameter estimation.

Example: A semiconductor manufacturer applies the Lilliefors test to wafer thickness measurements (n = 200). Because the population mean and standard deviation are unknown and estimated from the sample, the Lilliefors correction is essential; the raw K-S test without correction would understate the evidence against normality for these data.

Jarque-Bera Test

The Jarque-Bera (JB) test evaluates normality based on the sample skewness and excess kurtosis. Under normality, skewness = 0 and excess kurtosis = 0. The test statistic combines the squared skewness and squared excess kurtosis, scaled by the sample size, and follows an approximate chi-squared distribution with 2 degrees of freedom under the null hypothesis. The JB test is particularly sensitive to distributional shape (asymmetry and tail weight) rather than location or scale departures, complementing the tail-sensitive AD test.

Example: Cycle time data from a service process is often right-skewed (most jobs complete quickly; a few take very long). The Jarque-Bera test will typically detect this skewness strongly, even when the K-S maximum-distance test may not flag the same departure as significant.

Information on Distribution Fitting

When process data are significantly non-normal, the Distribution Advisor fits a comprehensive set of candidate distributions and identifies the one that best describes the data. Capability indices computed under the correct distributional model are more accurate predictors of actual nonconformance rates than normal-theory indices applied to non-normal data.

Candidate Distributions

The Distribution Advisor evaluates up to 16 parametric families. Two-parameter families fitted are: Normal, Lognormal, Gamma, Weibull, Exponential, Beta, Logistic, Log-logistic, Cauchy, and Uniform. When the three-parameter option is enabled, three-parameter Weibull, Lognormal, and Gamma distributions (with a shift/threshold parameter) are also fitted. Each distribution is fitted by maximum likelihood estimation.

Goodness-of-Fit Scoring

Distributions are ranked by a composite scoring method that combines the Akaike Information Criterion (AIC), Bayesian Information Criterion (BIC), and the p-value from the Kolmogorov-Smirnov or Anderson-Darling goodness-of-fit test. AIC and BIC penalise model complexity (number of parameters) to prevent overfitting; lower AIC/BIC indicates a better-fitting, more parsimonious model. The composite score converts each criterion to a rank and averages across criteria, so that the top-ranked distribution performs consistently well across all three measures.

Probability Integral Transform (PIT)

Once the best-fitting distribution F(x) is identified, the Probability Integral Transform maps each observed value xi to ui = F(xi), which is uniformly distributed on [0,1] if the model is correct. Applying the normal quantile function to ui gives zi = Φ−1(ui), which is standard normally distributed. Capability indices computed on these z-values are distribution-free and correctly account for the actual shape of the process distribution. The distribution-based Cpk reported in the Distribution Advisor section of the HTML report is derived from this PIT approach and will generally differ from the normal-theory Cpk in the main output tables; this is by design and not a discrepancy.

Box-Cox Transformation

The Box-Cox power transformation family x(λ) = (xλ − 1) / λ (with the log transform as the limit λ → 0) is a flexible parametric approach to normalising positively skewed data. The optimal λ is estimated by maximum likelihood, maximising the log-likelihood of the transformed data under a normal model. After transformation, all standard normal-theory capability indices are computed on the transformed scale. The procedure reports the estimated λ, its 95% confidence interval, and notes the interpretation (e.g., λ ≈ 0 corresponds to a log transformation; λ ≈ 0.5 to a square root transformation; λ ≈ 1 indicates the data are already approximately normal).

Example: Particulate contamination measurements from a cleanroom process are strongly right-skewed with values ranging from near-zero to several hundred. A Box-Cox analysis yields λ = 0.18, close to a log transformation. Capability indices computed on the transformed data (and back-transformed for reporting) give a more accurate picture of the true nonconformance rate than normal-theory indices applied to the raw skewed data.

Information on the Charts

Histogram with Normal Curve

The histogram divides the data into equal-width bins and plots the frequency (or density) of observations in each bin. The overlaid normal curve is computed from the sample mean and within-subgroup standard deviation. Vertical reference lines mark the LSL, USL, process mean (μ), and the ±3σW natural tolerance boundaries. When the normal curve extends visibly beyond the specification limits, the expected PPM nonconforming can be read qualitatively from the tail areas.

Normal Probability (Q-Q) Plot

The ordered sample quantiles are plotted against the theoretical quantiles of the standard normal distribution. Perfect normality produces a straight line. Systematic departure patterns are diagnostic: an S-shaped curve indicates heavier tails than normal (leptokurtosis or platykurtosis); a concave or convex curve indicates skewness; a step pattern indicates discreteness or rounding. Points near the extremes that deviate from the line often represent outliers or a second process stream.

Run Chart

The run chart plots each individual measurement in time order (or by observation index). A centre line at the process mean is shown. The run chart is the primary tool for assessing process stability before computing capability indices. Trends (consistent upward or downward movement), shifts (sudden changes in level), cycles, or clustering patterns all indicate that the process is not in statistical control and that capability indices computed from such data do not reliably predict future performance.

I-MR Chart

The Individuals (I) chart plots each observation with three-sigma control limits UCL = μ + 3σW and LCL = μ − 3σW, computed from the within-subgroup (MR-bar-based) sigma estimate. The Moving Range (MR) chart plots the absolute difference between consecutive observations with its own UCL = D4 × MR-bar (D4 = 3.267 for n = 2). Points outside control limits flag individual out-of-control observations; systematic patterns within limits indicate assignable causes that do not produce extreme values.

Capability Plot

The capability plot overlays the process data distribution (histogram bars with normal density curve and/or KDE) on the specification window defined by LSL and USL. The display communicates at a glance whether the process distribution is centred within the tolerance and how much of the distribution tail extends beyond each limit. The within-sigma and overall-sigma fitted curves may both be shown to illustrate the gap between potential and actual capability.

Box Plot

The box plot shows the median (centre line), interquartile range (box), and whiskers extending to 1.5 × IQR beyond the quartiles. Observations beyond the whiskers are plotted individually as potential outliers. When a grouping variable is specified, side-by-side box plots are produced for each subgroup level, enabling visual comparison of subgroup medians and spreads.

Violin Plot

The violin plot augments the box plot with a mirrored kernel density estimate on each side, showing the full shape of the distribution including multimodality, skewness, and density concentration. Wider sections of the violin indicate more observations at that value. Violin plots are particularly useful when comparing distributions across subgroups to identify differences in shape, not just location and spread.

Kernel Density Estimate (KDE) Plot

A smooth nonparametric density estimate using a Gaussian kernel with Silverman's bandwidth h = 0.9 × min(s, IQR/1.34) × n−1/5. The KDE does not assume any parametric form and reveals features of the process distribution (asymmetry, multiple modes, shoulder peaks) that the histogram may obscure due to binning. Specification limit lines are overlaid for capability assessment.

Summary Report Chart

A multi-panel composite chart that combines the histogram with capability overlay, normal Q-Q plot, run chart, and a text panel of key capability statistics in a single graphic. This is designed for inclusion in quality reports and management presentations where a single-page visual summary of the capability study is required.

Six-Pack Chart

The six-pack (inspired by the Minitab Process Capability Sixpack) arranges six standard diagnostic panels in a 2 × 3 or 3 × 2 grid: (1) run chart, (2) Individuals control chart, (3) Moving Range chart, (4) capability histogram with normal curve and spec limits, (5) normal probability plot, and (6) a capability indices summary table. The six-pack is the standard deliverable for AIAG-compliant capability studies and provides a comprehensive, self-contained analysis of both stability and capability.

Validation and Error Messages

The procedure validates all inputs before analysis. Any validation warnings or non-fatal errors are collected and displayed as a Process Capability: Warnings pivot table in the SPSS Output Viewer. Fatal errors that prevent analysis from proceeding are also shown there and stop execution immediately. All messages appear in the Output Viewer; the Syntax Editor window does not receive procedure messages.

Common validation messages include: no process variables specified; no specification limit provided (LSL and USL both absent); LSL greater than or equal to USL; fewer than 2 non-missing observations for a variable; sigma multiplier outside the valid range (must be > 0); confidence level outside (0, 1); and target value specified without both LSL and USL (required for Cpm). Warnings (non-fatal) are issued when a variable has fewer than 30 observations, when the normality tests indicate significant departures from normality, when outliers are detected, or when the Box-Cox transformation cannot converge.

Syntax

The full command syntax is:

STATS PROCESS CAPABILITY VARIABLE = varlist [GROUPVAR = varname]
 /CRITERIA LSL = number USL = number [TARGET = number]
   [SIGMA = {3|4|6|number}] [CONFIDENCE = number]
   [SIGMAMETHOD = {POOLED|RBAR|SBAR|MRBAR}]
 /STATISTICS [NORMALITY = {YES|NO}] [PPM = {YES|NO}]
   [CPM = {YES|NO}] [ZBENCH = {YES|NO}] [DPMO = {YES|NO}]
   [YIELD = {YES|NO}] [SKEWNESS = {YES|NO}]
