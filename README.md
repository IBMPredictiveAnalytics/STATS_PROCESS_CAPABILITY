# STATS_PROCESS_CAPABILITY


---
Requirements
----
- IBM SPSS Statistics 24 or later
- R 4.0 or later 
- R packages: nortest, e1071, png, jpeg


---
Installation instructions
----
1. Open IBM SPSS Statistics
2. Navigate to Extensions -> Extension Hub 
3. Search for **STATS PROCESS CAPABILITY** and click Ok. Your extension will be available.

Alternatively, install manually:
1. Download `STATS_PROCESS_CAPABILITY.spe`
2. Navigate to Utilities -> Extension Bundles -> Install Local Extension Bundle
3. Select the downloaded `.spe` file and click Open
